# dsbot (Railway)
## Env vars (минимум)
- DISCORD_TOKEN (или DISCORD_BOT_TOKEN) = Bot Token
- DISCORD_APP_ID (или DISCORD_CLIENT_ID) = Application ID
- DISCORD_GUILD_ID (опц. для быстрых команд, иначе глобально)
- ADMIN_ROLE_ID (опц. роль админа)
- APANEL_PASSWORD (опц. пароль по умолчанию, можно менять /apanel_set)

## Команды
/panel
/apanel password:...
/apanel_set password:...
/s text [channel]
/kick user [reason]
/ban user [minutes] [reason]
/clear [count] [days]
